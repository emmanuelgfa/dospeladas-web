# Dos Peladas Hostal · Sitio web

Página de una sola pantalla para [Dos Peladas Hostal](https://dospeladas.com/), cabañas de bioconstrucción sobre ruedas en Mendihuaca, Sierra Nevada de Santa Marta.

Dos propuestas de diseño:

- **Opción C · Atardecer en Palomino** (`/`, raíz)
- **Opción A · Selva y madera** (`/opcion-a/`): cortina de hojas de palma al cargar, capas de follaje con parallax y movimiento del mouse, hojas cayendo, manifiesto que se ilumina palabra por palabra, fotos con máscaras orgánicas que cambian de forma, cabañas apiladas al hacer scroll, el río revelándose a través de una ventana que se abre e imágenes que siguen al cursor en la lista de planes.

Opción C:: la paleta pasa de dorado a madera oscura con el scroll, textura de veta de madera, cabañas en scroll horizontal, parallax, contadores animados y reserva por WhatsApp.

Ver en local:

```bash
python3 -m http.server 8000
```

Luego abrir http://localhost:8000. Es HTML/CSS/JS sin dependencias, listo para GitHub Pages.
